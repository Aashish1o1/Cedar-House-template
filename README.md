# Cedar House - Premium Hotel Website Template

A premium, modern and fully responsive hotel website template built with pure HTML, CSS and JavaScript.

Designed for hotels, resorts, boutique stays, homestays, villas, guesthouses and other hospitality businesses.

## Live Demo

[View Live Demo](YOUR-VERCEL-URL)

## Features

- Premium hotel-focused UI/UX
- Fully responsive design
- Mobile-friendly navigation
- Full-screen hero section
- Rooms and suites section
- Room pricing
- Hotel story section
- Experiences and amenities
- Image galleries
- Location section
- Google Maps integration
- WhatsApp contact button
- Guest reviews
- Booking interface
- Guest information form
- Check-in and check-out date selection
- Room selection
- Guest selection
- Booking price summary
- Responsive mobile layout
- Smooth scrolling
- Easy customization
- Lightweight frontend
- No framework required

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
