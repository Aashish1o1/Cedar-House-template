# Cedar-House-template
A premium, responsive hotel website template built with pure HTML, CSS and JavaScript.  Designed for hotels, resorts, boutique properties, homestays, villas, guesthouses and mountain stays.
## Live Demo

[View Live Demo](YOUR-VERCEL-URL)

## Features

- Premium hotel-focused UI/UX
- Fully responsive design
- Mobile-friendly navigation
- Hero section
- Rooms and suites section
- Room pricing
- Hotel story section
- Amenities and experiences
- Image galleries
- Guest-focused content sections
- Location section
- Google Maps integration
- WhatsApp contact button
- Booking interface
- Guest information form
- Responsive mobile design
- Smooth scrolling
- Easy customization
- Lightweight frontend
- No frontend framework required

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
